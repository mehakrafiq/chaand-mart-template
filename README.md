# Chaand Mart: return check

Starter repo for Session 5. Synthetic data only.

- `returns.py`: the spec for `can_return`, and the function you write.
- `tests/test_returns.py`: four tests written from the spec. They fail until the function is right.
- `sample_10.json`: 10 orders the tests use.
- `pull_request_checklist.md`: paste it into every pull request and tick it honestly.
- `readiness/`: the readiness exercise (homework, due before Session 7).

Run the tests:

    python -m pip install -r requirements.txt
    python -m pytest -q

Every push and pull request also runs the tests on GitHub (the Actions tab). A green tick means all tests passed.
